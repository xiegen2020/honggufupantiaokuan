导言

「鸿伴复盘」是一款纯本地、不联网的交易复盘与账本笔记应用，性质等同于一本电子笔记本。本政策用一句话概括我们的做法：我们不收集你的任何个人信息，你记录的一切都只保存在你自己的设备上。

请你在使用前完整阅读本政策，并特别阅读第二节「免责声明与风险提示」——本应用与证券市场相关，那一节界定了本应用"是什么"和"不是什么"。一旦你安装并使用本应用，即表示你已理解并同意本政策。本政策的每一条承诺都对应应用代码的真实状态，未申请的系统能力即不会发生相应行为。

一、我们不收集任何个人信息

  • 本应用不需要注册、不需要登录、没有账号体系。
  • 我们不收集、不传输、不存储你的任何个人信息，包括但不限于：姓名、手机号、邮箱、设备标识符（如 OAID / 序列号）、通讯录、通话记录、短信、相册、位置信息。
  • 本应用没有申请网络权限，运行期间不向任何服务器发起网络请求，也无法将你的数据上传到我们或任何第三方。
  • 本应用不接入任何第三方 SDK（含统计、推送、广告、崩溃上报、社交登录等），不存在第三方替你收集数据的通道。
  • 我们看不到你的任何记录内容。你在应用里录入的账户、持仓、批次、成交、现价、复盘文字与交易计划，全部只留在你的设备本地。

二、免责声明与风险提示

本节的目的是把本应用的边界写清楚：它是一个记录工具，不是证券服务。

1. 本应用是记账与复盘笔记工具，不是证券服务。 本应用不提供行情数据、不提供证券资讯、不提供投资建议或投资顾问服务、不预测市场、不推荐任何证券、不提供任何委托下单或交易通道，也不归集、代理、管理你的资产。你无法在本应用内完成任何一笔真实交易。

2. 我们不是证券期货业务机构。 我们是软件开发者，未取得也无意在未获批准的情况下从事须经《经营证券期货业务许可证》等许可方可开展的证券期货业务。如本应用的功能或表述被有权机关或应用分发平台作出不同定性，我们将按其要求调整功能或下架处理，并在本政策中同步更新。

3. 屏幕上所有数字都来自你本人录入，不是市场数据。 本应用不联网、不获取行情，因此界面中出现的每一个价格、数量、市值、成本、盈亏、胜率、百分比，都是你手工录入的数值或对这些数值的算术结果。它们不代表任何标的的真实现价、估值、涨跌幅或走势，可能与实际市场数据相差极大。请勿把本应用中的任何数字当作行情使用，也不要据此判断交易时机。

4. 「买入 / 卖出 / 分红 / 止损 / 目标仓位 / 占比」只是你给自己的记录打的标签和一道算术。 这些词在本应用中仅用于让你标注、统计和回顾你自己的记录。仓位与占比相关计算只是"以你输入的总资产和百分比算出对应股数"这类确定性换算，输入由你给出、结果随之而来，其中不包含我们对于标的选择、买卖时机、仓位轻重的任何意见或倾向。任何"按百分比控制仓位"的算法都不构成资金管理与投资建议。

5. 历史复盘与统计描述过去，不代表未来。 应用内的收益、回撤、胜率、连续记录等统计，均由你自己录入的历史数据算出，用途是帮助你总结个人行为。证券市场存在价格波动，证券投资可能造成本金部分或全部损失，过往记录不预示未来表现。

6. 交易决策与后果由你自行承担，我们不承担赔偿责任。 你在应用外作出的任何投资决定及其全部后果，均由你独立判断并自行承担。我们不接触你的账户与资产，无法审查、干预、暂停或撤回你的任何操作，也不会对使用本应用或信赖其中任何数值、计算结果而造成的损失承担责任。本应用不收取任何佣金、服务费或交易分成，不接收任何资金，因此不存在代客理财或利益冲突关系。

7. 数据只在你本机，丢失风险也只在你的掌控范围。 由于我们不持有你的任何数据，一旦记录丢失（设备损坏或丢失、系统升级异常、卸载应用、误清空、忘记备份口令、你自行保存的备份文件缺失或损坏等），我们无法为你恢复任何一条记录，也无从代为找回。请在进行重要操作前按第六节所述主动加密备份，并自行妥善保管备份内容与口令——口令遗失后该备份不可恢复。

8. 随包名录仅辅助录入，不保证准确。 安装包内的证券代码与名称对照名录只用于在你录入标的时补全名称，其准确性、完整性、时效性均不作保证，可能存在过时、缺漏或错误；它不构成证券信息服务，也不作为任何投资参考（详见第六节）。

9. 请合法使用本应用。 你不得利用本应用及其内文本从事非法证券投资咨询、非法荐股、代客理财、编造并传播证券虚假信息等法律、行政法规禁止的活动。应用内的复盘观点属于你的个人记录，仅在你主动分享时才会离开本机，分享行为及其后果由你负责。

10. 不免除法定责任。 本节及本政策其他条款均不排除或限制我们依照法律强制性规定应当承担的责任；如某一条款被认定为无效或不可执行，不影响其余条款的效力。本政策适用中华人民共和国法律（为本政策之目的，不含港澳台地区法律）。

三、你的数据保存在哪里

你的记录写入应用私有沙箱内的加密 SQLite 数据库，仅存在于本设备：

  • 该数据库随应用卸载而彻底清除；
  • 数据不会随系统云备份或换机迁移离开本机（本应用主动关闭了系统级备份与恢复能力）；
  • 除你在下文第六节主动发起的"备份导出 / 复盘分享"外，数据不会以任何形式离开本应用沙箱。

四、关于两个系统权限（申请即使用，不申请即无该行为）

本应用仅申请以下两个系统授权权限，二者均为随安装生效、不弹出授权框的系统权限；本应用不申请其余任何权限。每一项权限的用途如下，未申请的行为一定不会发生。

1. ohos.permission.ACCESS_BIOMETRIC（生物识别认证）

  • 用途：仅在你进出应用时，调用设备系统提供的指纹 / 人脸 / 锁屏密码认证，用于本机的应用锁功能。
  • 本权限只调用系统认证能力，本应用不采集、不传输、不存储任何生物特征信息（指纹图像、人脸数据、密码等）。认证过程完全在你的设备本地由系统安全组件完成，本应用只收到"本次认证是否通过"这一个结果，接触不到你的生物特征或锁屏密码本身。 生物特征属于敏感个人信息，正因如此我们选择"只用系统结果、绝不触碰原始特征"的实现方式。
  • 关闭应用锁后，本应用不再触发上述认证。

2. ohos.permission.PRIVACY_WINDOW（隐私窗口 / 防截屏）

  • 用途：将应用界面设置为系统隐私模式，使截屏与录屏取不到屏幕内容、最近任务（多任务）缩略图被打码，用于保护你在公共场合不被旁人看到屏幕上的数字。
  • 该权限只影响系统对"能否截取 / 显示本应用画面"的处理，不采集任何数据，不上传任何内容。此功能可在「设置 - 隐私与安全」中开启或关闭（默认开启）。

五、占比模式（只改变显示，不改变数据）

开启"占比模式"后，应用内的页面会把金额与股数改显为"占当日总资产的百分比"，屏幕上不再出现绝对数额；这只是显示层的换算，不改动数据库里的任何一条记录，你录入的真实价格、数量与现金照原样保存，各项计算仍按真实数值进行，关闭开关界面立即恢复。该开关是本机偏好设置，不包含在备份文件中，也不会随换机迁移；本应用未因该功能申请任何新权限，也绝不会因此上传任何数据。桌面卡片上金额的可见性由应用锁单独控制，与本模式无关。

六、只有你主动发起，数据才可能离开本机

1. 加密备份与恢复（剪贴板：只写不读）

  • 当你点击"复制备份"时，应用把整库数据导出为 JSON，用你设定的口令进行加密（口令派生 + 对称加密 + 完整性校验），再把加密后的密文写入系统剪贴板，由你自行粘贴保存到设备之外。
  • 应用只向剪贴板写入内容，不申请、也不使用任何"读取剪贴板"的权限，不会程序化读取剪贴板。 恢复数据时，是你把密文用系统粘贴控件主动填入输入框，应用才对输入框中的内容进行解密校验——读取动作由你在界面上完成，不是应用后台发起。
  • 写入剪贴板的内容始终是密文；你的口令不在备份文件内，也不写入数据库、不写入日志，只存在于你操作的那一刻。忘记口令，这份备份将无法恢复。

2. 复盘分享（经系统分享面板，由你选择接收方）

  • 当你点击"分享"时，应用把当前复盘正文（含尚未保存的草稿）、日期、关联标的与标签交给系统分享面板，由你选择备忘录等接收应用完成保存。
  • 该操作由你主动发起，只分享你选定的复盘文字，不会自动导出账户资金或交易流水，也不会自动保存应用内草稿。
  • 请注意：接收你分享内容的应用，可能按其自身设置把内容同步到其云端。已分享出去的内容不再受本应用与本政策约束，请依据接收应用的隐私政策管理这些内容。
  • 你分享出去的复盘内容属于你的个人观点。请勿在分享时将其表述为我们的投资意见或荐股建议（见第二节）。

3. 随包附带的证券代码 / 名称名录

  • 安装包内附带一份证券代码与名称对照名录（仅静态文本），唯一用途是在你录入标的时做名称自动补全，让你少打几个字。
  • 该名录不含行情、不含估值、不含任何推荐或投资建议，也不联网更新；它只是本应用运行所需的本地输入辅助资源，不构成任何证券信息服务。

七、未成年人

本应用是面向个人的记录与自我总结工具，不提供行情、不提供投资建议、不能下单交易，不面向未成年人。我们建议未成年人的监护人引导其合理使用；若你发现在未获监护人同意的情况下有未成年人使用了本应用，可通过本政策联系方式与我们联系。由于我们不收集任何个人信息，也无从远程识别或获取未成年人数据。

八、你的权利

因为所有数据都只在你本机、我们不经手任何个人信息，你的权利在本地即可完全行使：

  • 查阅 / 导出 / 删除：你可在应用内查看、编辑、删除任意记录，或在「设置 - 数据管理 - 清空数据」中一键清空全部本地数据（该操作不可撤销，需二次确认）；单条删除会在屏幕上提供一次"撤销"。
  • 卸载即清除：删除应用会一并清除其私有沙箱内的全部数据库与偏好数据。
  • 无需账号即可行使：不存在"提交申请等待我们后台处理"的环节，因为数据本就不在我们手里。
  • 如需就本政策提问，见下方联系方式。

九、数据安全

  • 数据以加密 SQLite 存储于应用私有沙箱，其他应用无法直接读取。
  • 备份内容在离开剪贴板前已完成加密（对称加密 + 完整性校验，先加密后认证），口令经迭代派生增强抗暴力破解能力。
  • 由于不联网、无第三方 SDK，本应用不存在数据传输环节与第三方共享环节。
  • 若将来发生影响本政策的安全变化，我们会按第十节告知。

十、政策更新与本政策的生效

若本政策发生变化，我们会随应用版本一并更新，并在应用内「设置 - 隐私与安全 - 隐私政策」页及本公网页面展示新的版本号与生效日期；重大变更还会以应用内提示的方式告知。当前版本 1.3，生效日期 2026-10-06。
